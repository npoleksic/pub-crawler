# HOW A RUN WORKS
# 1. The [SEARCH] terms query Europe PMC. If you have an OpenAlex key and
#    Europe PMC misses 10% or more of a sample of OpenAlex results, OpenAlex
#    is searched too. Only papers with a DOI are kept.
# 2. Gemini screens the papers in batches of 20. Papers that score 6 or
#    higher are checked again in batches of 10.
# 3. Papers that score 7 or higher are emailed.
#    (Batch sizes, score limits, and scoring weights are settings in crawl.py.)
#
# ADDITIONAL CONSIDERATIONS
# - The search only needs to find every relevant paper. The screening
#   removes the rest, so a broad search is acceptable. But each extra
#   20 papers costs 1 more request and makes the run longer.
# - One broad word (for example "cortex" or "patients") can add thousands
#   of papers. Short abbreviations can match other fields that use the
#   same letters. Prefer full names or specific phrases.
# - The number of papers increases with DAYS_BACK. Each database stops at
#   5,000 papers per run. Papers after that are not screened, and a
#   warning is shown.
